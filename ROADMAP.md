# ROADMAP.md - Guizang Social Card Skill

This roadmap outlines strategic directions and potential enhancements for the Guizang Social Card Skill, focusing on leveraging its unique position in the AI agent and social design space.

## Vision

To be the most intelligent, design-centric, and platform-optimized AI agent skill for generating social media visual content, empowering creators and brands with effortless, high-quality visual storytelling.

## Strategic Pillars

1.  **Deepen AI Agent Intelligence**: Enhance the skill's ability to understand context, adapt design, and source content autonomously.
2.  **Expand Design System & Customization**: Offer more curated design options while maintaining visual integrity.
3.  **Broaden Platform Integration & Output**: Support more social media platforms and diverse output formats.
4.  **Foster Community & Ecosystem**: Encourage contributions and integrate with broader AI agent platforms.

## Q3 2024 - Q4 2024: Core Enhancement & Intelligence

### 1. Enhanced Contextual Adaptation (Pillar 1)
    -   **Smart Layout Selection**: Automatically choose the most appropriate layout(s) based on content type (e.g., product review, travelogue, data report).
    -   **Content-Aware Image Sourcing**: Improve image search relevance and quality based on text keywords and sentiment (addressing Issue #3).
    -   **Dynamic Text Readability**: Implement automatic contrast adjustments for text over images (addressing Issue #1), including text shadows or adaptive overlays.
    -   **Tone & Voice Adaptation**: Introduce subtle typographic or color theme shifts based on content's emotional tone.

### 2. New Layouts & Themes (Pillar 2)
    -   **Interactive Elements for Static Output**: Add new layouts that simulate interactive elements (e.g., poll results, quizzes) through clever static design.
    -   **Community-Contributed Themes**: Define a clear process for community-submitted themes and layouts.
    -   **"Minimalist Tech" Theme**: A new Swiss-inspired theme optimized for software tutorials and app showcases.

### 3. Output & Export Flexibility (Pillar 3)
    -   **Video Snippet Export**: Generate short video clips (e.g., MP4/GIF) from carousels with subtle animations, suitable for Reels/TikTok covers.
    -   **Web Story / Web Carousel Export**: Output a simple, interactive HTML-based web story or carousel for embedding.

## Q1 2025 - Q2 2025: Advanced Features & Ecosystem Expansion

### 1. Multi-Modal Content Integration (Pillar 1)
    -   **Video & Audio Transcription**: Ability for the agent to take video/audio input, transcribe it, and generate social cards from key points.
    -   **Data Visualization Skill**: Deeper integration with structured data inputs to generate advanced charts (beyond current simple bars/KPIs).

### 2. Design System Evolution (Pillar 2)
    -   **Design Token Integration**: Move towards a more robust design token system, allowing easier theme customization without breaking layouts.
    -   **A/B Testing Skill**: Allow the agent to generate multiple versions of a social card based on user prompts for A/B testing visual impact.

### 3. New Platform Targets (Pillar 3)
    -   **Instagram Reels Cover/Carousel**: Optimize layouts and aspect ratios for Instagram.
    -   **Twitter/X Cards**: Specific templates for Twitter cards with proper meta-tag generation suggestions.

### 4. Agent Ecosystem Integration (Pillar 4)
    -   **API for Direct Tool Use**: Provide a simple API for other non-agent applications to programmatically use the skill's rendering capabilities.
    -   **Plugin for Popular AI Assistants**: Explore integration as a plugin for broader AI assistants beyond Claude/Codex.

## Future Exploration (Long-Term)

-   **Localization**: Expand design systems and content adaptation for global markets.
-   **Brand Kit Integration**: Allow users to upload brand guidelines (logos, fonts, color palettes) for consistent output.
-   **AI-Driven Copywriting Suggestion**: Integrate a copywriting skill to suggest or refine text for social cards.

This roadmap is subject to change based on community feedback, technological advancements, and market needs.
